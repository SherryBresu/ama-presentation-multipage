# Sherry — Interactive AMA Presentation

## Files
- `index.html` — 01 Introduction
- `journey.html` — 02 My Journey
- `work.html` — 03 My Work
- `hobbies.html` — 04 Outside Work
- `favorites.html` — 05 Favorites
- `about.html` — 06 Beyond the Job Title
- `goals.html` — 07 Dreams & Goals
- `ama.html` — 08 Ask Me Anything
- `style.css` — shared design
- `script.js` — shared navigation/interactions
- `assets/` — images and other media

## Controls
- Left / Right Arrow — previous / next page
- Space — next page
- Page Up / Page Down — previous / next
- Home — first page
- End — last page
- F — fullscreen
- Swipe left/right on mobile
- Moon button — dark mode (saved in browser)

## GitHub Pages
Upload the entire folder to a GitHub repository. Go to Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

Open the generated GitHub Pages URL. `index.html` is the first page.

## Important
Keep all HTML files, `style.css`, `script.js`, and the `assets` folder together. Navigation uses the filenames above.
